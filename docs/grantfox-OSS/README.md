# GrantFox OSS — Screenshot / Evidence

Put all visual proof for your build issue here, in a **subfolder named after your issue**.

## Naming

```
docs/grantfox-OSS/<issue-slug>/
```

Examples:

- `issue1-vyc_mint_frontend/`
- `issue3-parametric_insurance/`
- `issue5-freighter_wallet_provider/`

## What goes inside

- Frontend running on **localhost** (feature working)
- Build/compile output (terminal) showing success
- Smart-contract tests passing
- Any UI state your change produces

## Rules

1. Create your own subfolder — don't dump files at the repo root.
2. Reference paths relatively from your PR description.
3. Real evidence only. Fabricated or recycled screenshots = closed PR + ban.
